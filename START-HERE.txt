CARBON-AWARE SMART MOBILITY — REAL-AREA UPGRADE

FASTEST START: Node.js 24 recommended. The production build is included.
1. Extract the ZIP.
2. Open a terminal inside the carbon-mobility folder.
3. Copy .env.example to a new file named .env.
4. Put your openrouteservice key after ORS_API_KEY= in .env. Keep it private.
5. Run: npm start
6. Open http://localhost:4173 in your browser.
7. Select Real-area planner. Enter actual location coordinates and find routes.
